# Entre-Líneas 📚

Una página web para una librería donde los lectores pueden descubrir, conocer y conectar con libros únicos. 

## 🧾 Secciones del sitio

- **Inicio** (`Entre Líneas.html`)
- **Nosotros** (`Nosotros.html`)
- **Términos y condiciones**
- **Catálogo de libros** (`books.html`)
- **Contacto**

## 🎨 Tecnologías utilizadas

- CSS3
